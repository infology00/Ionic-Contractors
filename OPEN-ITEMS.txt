3. VERIFIED AS BUILT — no need to re-test from scratch
-------------------------------------------------------------------------------

  - 12 pages build clean. No broken internal links, no root-absolute paths,
    no missing alt text, no missing width/height, no unresolved template
    tokens, no unlabelled form controls.
  - No horizontal scrolling at 320, 375, 768, 1280 or 1440 pixels.
  - Exactly one <h1> per page; unique title and meta description on each.
  - Every path is relative, so the site opens from disk and can be deployed
    into a subfolder.
  - Scroll-scrub confirmed driving video.currentTime on both film stages.
  - Beat cross-fades never drop below 50% combined visibility — there is no
    blank frame between beats.
  - Faded-out beats are inert from the first render; confirmed by attempting
    to focus a link inside a hidden beat and being refused.
  - The opening beat ships at rest in the markup, so the hero is correct even
    before the first animation frame.
  - Mobile drawer: opens, traps focus, Escape closes, focus restored, page
    scroll locked and released.
  - Accordion: aria-expanded toggles, panel hidden on collapse, with a timer
    fallback so it cannot get stuck in the tab order.
  - Form validation: required fields, email format, phone length, inline
    errors, focus moved to the first bad field, live-region announcement.
  - A successful submit composes the mailto: and pushes the analytics event.
  - Static rendering (JS off / reduced motion) shows every beat in normal
    flow over the poster still — no hidden content, nothing left inert.
  - Zero console errors; zero failed resource loads across all pages.
